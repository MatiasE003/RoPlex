# AGENTS.md

## Repository State
- This repository contains a Manifest V3 Chrome extension for Roblox Home and game pages on `https://www.roblox.com`.
- `manifest.json` injects `content.css` and the classic `content.js` loader at `document_start` on Home. The loader activates the shell synchronously, then imports the isolated ES modules under `content/`; those packaged modules are exposed only to `https://www.roblox.com/*` through `web_accessible_resources` because Chrome does not support module declarations for manifest content scripts. The Home bootstrap reads the authenticated account from `users.roblox.com`, the user's Robux balance from `economy.roblox.com`, friends from `friends.roblox.com`, the authenticated user's custom names for those friends from `contacts.roblox.com`, presence from `presence.roblox.com`, circular headshots and game icons from `thumbnails.roblox.com`, and the authenticated Home discovery feed from `apis.roblox.com` through the background service worker.
- Game pages load `server-browser.css` and `server-browser.js`; `roblox-page-bridge.js` runs in the page's main world on Home and game pages so direct joins use Roblox's official `GameLauncher`.
- Game-page match patterns cover both `/games/*` and locale-prefixed paths such as `/es/games/*`; `https://www.roblox.com/*` is also a host permission because dynamic main-world injection uses `chrome.scripting`.
- `background.js` owns Roblox API orchestration, bounded cursor pagination, retry/backoff, and the expiring region/datacenter cache. Region POSTs execute in the Roblox tab's main world so their origin/referrer match the website request; `GameJoinRegion` is extracted from the JSON stored in `joinScript.SessionId` when Roblox does not return it as a direct property. The public IP from `joinScript.UdmuxEndpoints` is geolocated through `https://ipwho.is`, with request deduplication, rate-limit handling, and separate expiring IP and `DataCenterId` location caches.
- `network-rules.json` contains a single scoped MV3 `declarativeNetRequest` rule that sets Roblox's required `User-Agent` only for `join-game-instance` requests initiated by `www.roblox.com`.
- The `content/` modules replace Roblox Home with the first production slice of the adaptable Home design. `main.js` owns registration and mounting, `home-app.js` owns the shell and account bootstrap, `friends.js`, `game-feed.js`, and `home-search.js` own their UI domains, while `config.js`, `messaging.js`, and `ui.js` contain shared contracts and helpers. They request `GET_HOME_BOOTSTRAP`, `GET_HOME_FRIENDS`, `GET_HOME_CONTINUE`, `GET_HOME_FAVORITES`, and `GET_HOME_RECOMMENDED` from `background.js`, render the authenticated user's identity and avatar, update account-specific links, and expose independent loading, error, and retry states. Friends are sorted by presence and the first seven are shown. Hovering or focusing a friend lazily requests `GET_HOME_FRIEND_PREVIEW`, which renders social counts, join date, activity, profile navigation, and an official direct Join action when Roblox exposes a public game instance. The top-bar search debounces `SEARCH_HOME_USERS` requests as the user types, displays up to eight matching profiles with direct profile links, and offers searches for players, experiences, communities, and Roblox documentation. Continue renders up to 30 experiences in Roblox's feed order, Favorites renders up to 30 publicly accessible favorites in Roblox's favorite order, and Recommended renders up to 50 valid personalized results returned by Roblox as a four-column landscape grid. All game cards show a thumbnail, rating, live player count, and direct game navigation. Vertical mouse-wheel input over either horizontal carousel moves it sideways and remains contained at either edge instead of scrolling the page. Continue and Recommended share the same authenticated discovery response through a 30-second background cache.
- `content.css` hides Roblox's original Home while the extension shell is active and contains the responsive desktop, compact-sidebar, and existing mobile styling for that shell. Friend activity labels use blue for Online/Studio, green for a visible game name or privacy-limited Playing state, and muted gray for Offline.
- `server-browser.js` detects game PlaceIds, requires the user to choose whether Roblox should return fuller or emptier servers first, analyzes up to a configurable public-server page limit with configurable worker concurrency, groups results by geolocated administrative region and country, and renders a region filter with live progress. Approximate locations come from the public UDMUX endpoint IP; compact labels prefer the administrative region over the city (for example, `São Paulo, Brasil`). Live result rendering is throttled to once per second so large analyses do not continuously rebuild the full UI.
- `server-browser.css` contains all Server Browser styling and follows Roblox's light/dark themes.
- Do not assume a package manager, build system, test runner, or bundled entrypoint until project files are added.

## Design Prototypes
- `ideas front/` is only a container for static design ideas that may guide future extension changes. Files in this directory are references, are not production extension entrypoints, and must not be treated as implemented functionality.
- `ideas front/adaptable-home.html` is the selected design reference for the ongoing replacement of Roblox `/home`; the other files in `ideas front/` remain alternative or historical concepts.
- `ideas front/adaptable-home.html` remains a static HTML/CSS reference with placeholder data and no application logic. Production behavior belongs in `content.js`, the `content/` modules, `content.css`, and `background.js`, and obtains dynamic Roblox data exclusively from public Roblox APIs.

- Expected Home behavior: Roblox's original Home is hidden, the adaptable Home shell renders immediately, and the account card plus sidebar resolve to the authenticated display name, username, avatar, profile, friends, and inventory links. The top bar shows the authenticated user's Robux balance between notifications and settings. Typing at least three characters in the top search returns up to eight matching Roblox profiles beneath the input after a short debounce; each result includes its headshot and opens the profile directly, while separate links search the same text in players, experiences, communities, or the official Roblox documentation. The Friends section resolves up to seven presence-sorted friends with their custom name when one is set, otherwise their Roblox display name, plus their headshot, current activity, and presence indicator. Online/Studio activity text is blue, visible game names and privacy-limited Playing text are green, and Offline remains muted gray. Hover or keyboard focus opens a profile preview; its details load once on demand and are cached for 5 minutes. Playing friends show the experience and Join button when Roblox exposes enough presence data, while private activity receives an explicit privacy message. Continue independently resolves recent experiences, Favorites independently resolves the authenticated user's publicly accessible favorite experiences, and Recommended independently renders up to 50 personalized landscape cards; all include thumbnails, ratings, and live player counts. Scrolling down over either carousel advances right, scrolling up advances left, and further wheel input at either horizontal edge is consumed without moving the page. Account, Friends, search, Continue, Favorites, Recommended, and preview failures have separate states; missing thumbnails fall back without failing their sections.
- Game-page verification: open `https://www.roblox.com/games/{placeId}/...`, confirm Server Browser appears above Roblox's server list without starting a request, choose fuller or emptier servers first, confirm live progress advances in the chosen player-count order, servers from different `DataCenterId` values in the same geolocated administrative region render together under a compact region/country label, cards show only players and FPS, filters reorder results, and `Entrar` opens the selected JobId.
- The Server Browser analyzes at most 20 public-server pages (up to 2,000 servers at 100 per page) and uses 20 concurrent join-game workers; edit `SERVER_BROWSER_CONFIG` in `server-browser.js` to tune both limits.
- Region checks run at a maximum of 8 requests per second globally, including retries. A Roblox `429` automatically reduces the rate by half, down to a minimum of 5 requests per second, observes a bounded `Retry-After` cooldown, and recovers gradually up to 8; edit the `region*` values in `SERVER_BROWSER_CONFIG` in `background.js` to tune this behavior.
- Region/datacenter cache entries expire after 5 minutes; edit `SERVER_BROWSER_CONFIG.cacheTtlMs` in `background.js` to tune the TTL.
- IP geolocation checks are limited to 10 requests per second, deduplicated by address and `DataCenterId`, and cached for 30 days; edit the `geolocation*` values in `SERVER_BROWSER_CONFIG` in `background.js` to tune these limits. Temporary lookup failures are negatively cached for 10 minutes, and provider `429` responses pause further lookups according to `Retry-After`.
